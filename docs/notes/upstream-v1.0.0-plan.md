## 2. Что это значит для кода

Риск регрессии низкий: `lib/*`, `client.js`, `locale/*` — полностью корпус-зависимые, кода менять не нужно. Зашитые числа есть только в двух местах манифеста инструментов и в `package.json`.

`test/*.mjs`: 59/66 проходят без правок, ломаются **8 ассерт-строк в 7 тестах** — все из-за счётчика/версии/одного сдвига top-1.

## 3. Решения, которые нужны от владельца продукта

### D-1. Гейт экспериментальных гайдов (18 штук: 8 Origin Trial + 10 volatile)

Upstream бросает `OriginTrialGateError`/`VolatileFeatureGateError` и требует `.mwgrc`-opt-in; у нас нет ни `.mwgrc`, ни чтения файлов пользователя (это часть модели безопасности). Варианты:

| | что делаем | объём | следствие |
|---|---|---|---|
| **A** | одна фраза в `SKILL.md`: экспериментальные API помечены в самом гайде | S | 0 кода, но модель не предупреждена |
| **B** | аннотировать при ретриве: баннер в начале `content` + `[experimental]` в строке результата поиска | M (~40–60 строк, 2 теста) | предупреждение есть, контент доступен; ни один существующий тест не трогает gated-id |
| **C** | fail-closed: `retrieve` отдаёт `gated` без конфиг-флага | M–L | по умолчанию отрежет `language-model`, `summarizer`, `webmcp`, `agentic-*`; меняет контракт `retrieve` |

### D-2. Объём 0.4.0

Обязательное ядро (O-1…O-6) + что-то из «желательного»:
`S-2` тест-инвариант «манифест ↔ файлы» (208/208, `prompt-api` не проиндексирован, все id — slug), `S-3` переписать тест лимита `retrieve` на инвариант (сейчас 119 140 / 120 000 — запас 860 символов, зависит от порядка), `S-6` лимиты в рендере из payload, `S-7` дедупликация id в `readCatalog`.

### D-3. Когда открывать PR в `awesome-dsh-plugin`

Гейт «репозиторий старше суток» открыт с 2026-11-09 01:55 UTC. Ветка готова (`metapeka:add-dsh-modern-web-guidance`, `aea183e`), но в её описании фигурируют 193 гайда — после 0.4.0 цифры в записи станут 208.

## 5. Что сознательно не делаем в 0.4.0

| Отказ | Причина |
|---|---|
| Эмбеддинги/векторный поиск (`gen/` = 9,16 МБ) | нарушает «ноль зависимостей» и размер пакета; наш лексический BM25 на новом корпусе даёт 29/30 top-1 |
| `legacy-scan` в 0.4.0 (движок 4,99 МБ, 4-шаговый flow) | в 0.4.0 не едет; в 0.5.0 — только если правила извлекаются в данные и скан остаётся без зависимостей (решение D-1 в §7) |
| `.mwgrc`-дискавери, baseline-баннеры, `set-*` | нет надёжного корня проекта в контексте инструмента; 0.5+ вместе с решением про config |
| Сборка индекса из markdown | метаданных в файлах нет; индекс — генерируемый артефакт upstream, его вендорим как есть |
| Новая UI-функциональность панели | ограничение релиза 0.4.0 |
| Переписывание исторических цифр в `audit/*` | это датированный аудит: правится квалификатором-датой, а не цифрами |
