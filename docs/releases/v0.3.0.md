# 0.3.0 — a client half: the Guidance Insights panel ✨

The plugin stops being tools-only: it now ships browser code and a sidebar panel that renders the
usage report the host already produces. No new tool, no new host service, no second implementation —
the panel reads `/guidance-stats --json` through the session bridge and draws it.

## ✨ Features

- **Guidance Insights panel**: an icon in the left rail opens a read-only panel in the central area —
  seven-day call count and hit rate, top queries with hits and misses, all **17 category-coverage
  rows**, missed queries, never-retrieved guides, and one Refresh control.
- **Bilingual** (EN/RU) and themed with host tokens only, so it follows the active theme in light and
  dark without a stylesheet of its own.
- **One file**: `client.js`, 789 lines, no bundler, no new dependency; it registers a lazy factory
  through `window.__ModuleLoader__.load({ id, factory })` and mounts into `sidebar.panellist` plus a
  keyed `main` slot.

## 🛠 Hardening

- The panel has no write path: no command with side effects, no host service, no network. Its only
  input is the JSON the `/guidance-stats` command returns.
- Usage counters remain local to the machine and can still be turned off entirely with
  `enabled: false` (ADR 0001).

## 📝 Skills and docs
