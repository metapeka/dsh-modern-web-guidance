# 0.7.1 — the scanner stops reading documentation 📖

A `.md` or `.mdx` file is no longer scanned: it is reported as skipped, with reason `extension`, and the
count in `skippedTotal` includes it. Code is unaffected — the allowlist is 18 source extensions, the caps,
the refusals and the rule table are exactly as they were. The change exists because prose quotes
anti-patterns: a README that says "use `dialog.showModal()` instead of `$.fn.modal`" is documentation, not
legacy code, and the panel's scan button was reporting 73 findings on a project whose only defect was its
documentation.

## 🧪 Behaviour changes

- **Prose is skipped, not read.** `.md` and `.mdx` left the allowlist, so a Markdown file met while walking
  is skipped with reason `extension` and counted in `skippedTotal`; a `.md` path named **explicitly** gets
  the same skip instead of an error. A project whose only defect is its documentation now scans clean.
- **A scan of this repository, before and after**: 200 files with **73 findings**, 71 of them in Markdown
  and `truncated: true` → **68 files with 82 findings**, 0 in Markdown, `truncated: false`.
- **That rise is not a regression, and the note will not call it one.** 61 of the 82 are the rule table
  itself — `lib/scan-rules.js` (18) and `test/scan-rules.test.mjs` (43) store every marker as data — 9 are
  deliberate fixtures, and the rest sit in tests and one audit repro. The old 200-file cap was consumed by
  the bundled corpus, so `lib/` and `test/` were never reached; the scan now covers the code.
- **Counters follow**: a Markdown-only project records a `clean` scan instead of a `findings` one, with
  `findings: 0`. No state-file field changed.

## 🧩 Compatibility

- Same tool, same arguments, same caps (16 paths, 200 files, 512 kB per file, 8 MB per call, 200 findings),
  same refusal codes, same text. Only the allowlist shrank, so a path that used to produce findings can now
  come back empty — that is the intended answer, not an error.
- Engines unchanged: DSH `>=0.2.0-rc.1 <0.3.0-0`, Node `>=22.19.0`. The panel's scan button needs no change,
  and `/guidance-scan` still refuses to run without an explicit path.

## 📦 Package

- **256 files, 895 kB packed, 2.6 MB unpacked** (measured by `npm pack --dry-run`) — no file added or
  removed, still **zero** runtime dependencies, Apache-2.0, sigstore provenance from the release workflow.
