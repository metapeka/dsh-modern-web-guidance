# 0.11.0 — the panel can act, and every action asks first ✍️

0.10.0 made the counters honest about whose numbers they are. 0.11.0 gives the panel hands: it writes for
the first time, to exactly two files, one entry at a time — behind a visible plan, a second, distinct
confirmation, and a refusal that is reported as a refusal. Same four tools, no new dependency.

## ✨ Features

- **Mute one finding, never a rule or a line.** `/guidance-suppress <siteId> [--dry-run]` appends one entry
  to `<workspace>/.suppress`, keyed by the 8-character site hash phase B compares, capped at 200 entries, a
  200-character reason and 256 KiB. A row offers **Mute**, the plan shows under it, only a second click appends.
  The muted finding keeps its place, order and count: `85 findings, 3 suppressed` in the scan, `Suppressed: 3 in
  the last scan (ls-13 2, ls-02 1) - muted, still findings` in the report, `muted` in the panel.
- **Offer a `.scanignore` line, and say what it does.** `/guidance-scanignore <pattern> [--dry-run]` appends
  exactly one line, never rewrites, and judges identity by effect (`report/` and `/report/` are one pattern).
  It makes the next scan read less and mutes nothing; the plan names the file's own line, the count it would
  reach and how wide the pattern is, and the panel keeps "reads less" apart from "muted" in all three languages.
- **Reset one slice instead of everything.** `--scan-only`, `--workspace <name|id|path>` and `--days N` narrow
  `--reset --yes`, which keeps the meaning it always had; each plan names the target, each result names what
  stayed.
- **Copy as JSON.** The panel copies the envelope it already holds: no host call, no file, no new command —
  and the button is absent when there is no report or no clipboard.

## 🧪 Behaviour changes

- **The panel is no longer read-only, and it is not a writer either**: every action is a command the host
  runs — four human commands now, not two — so a scan or a render still writes nothing, a single click writes
  nothing, and a refusal can never look like a success.
- **Muted is not fixed.** A suppressed site keeps its place in the scan and is never reported as "resolved" by
  the phase B comparison: the number sits beside the findings, it is never subtracted from them.
- **No reset, at any scope, opens the suppression file**: its messages end "The suppression file was not
  touched: muting is not a counter", and a `--days` reset adds that lifetime rule and guide totals carry no day.

## 🛠 Hardening

- **The reader stays forgiving; the writer does not.** Append-only, one fixed path, realpath-contained,
  temp-then-rename, and the result re-parsed through the scanner's own reader before the rename: a symlink, a
  directory or a malformed file is a refusal, and a failed write leaves the original byte for byte. `.scanignore`
  has no cap where `.suppress` does — deliberate, and the plan states the count without claiming headroom.
- **One identity, three readers.** `lib/site.js` is the single site derivation the scanner, the counters and
  the file all use, so a mute cannot name a different site than the scan that found it.

## 🧩 Compatibility

- **`version` stays `1`.** `suppressed` and `suppressedRules` are additive and clamped to `findings`; a
  document written before this release loads and renders byte-identically — zero prints nothing at all.
- **The four tools are untouched.** The chat row gains a ` (suppressed)` suffix and nothing else.

## 📝 Skills and docs

- [ADR-0003](../adr/0003-write-surface.md) licenses exactly two writes, and the
  [suppression contract](../notes/suppression-contract.md) fixes the file, its caps and the muted-not-fixed
  rule.

## 📦 Package

- **258 files, 971 kB packed, 2.9 MB unpacked** — two new modules (`lib/site.js`,
  `lib/suppress.js`), zero runtime dependencies, Apache-2.0.
- **463 tests in 18 files**: 459 passed and four skipped, every skip this machine's symlink restriction.

- Заглушить одно место — не правило и не строку: `/guidance-suppress <siteId> [--dry-run] [--reason <text>]`
  дописывает одну запись в `<workspace>/.suppress`, ключ — тот же 8-символьный хеш места, что и в фазе B;

- Заглушённая находка остаётся находкой: она сохраняет место, порядок и счёт, получает `suppressed: true`,
  и её по-прежнему считают все поверхности — скан печатает `85 findings, 3 suppressed`, отчёт
  `Suppressed: 3 in the last scan (ls-13 2, ls-02 1) - muted, still findings`, а панель помечает строку
  `muted`. Заглушено — не исправлено, и сравнение фазы B никогда не назовёт такое место «исчезнувшим».
- Игнорирование — не заглушение: `/guidance-scanignore <pattern> [--dry-run]` дописывает ровно одну строку,
  никогда не перезаписывает файл, а совпадение считает по эффекту (`report/` и `/report/` — один шаблон).
  Следующее сканирование читает меньше; панель так и говорит, ни в одном из трёх языков не смешивая слова.
- Сброс теперь можно сузить: `--scan-only`, `--workspace <name|id|path>`, `--days N`; голый
  `--reset --yes` стирает ровно то же, что и раньше. План называет цель, результат — что осталось.
- Ни один сброс, ни в каком объёме, не открывает файл подавлений: его сообщения кончаются словами «файл
  подавлений не тронут: заглушение — не счётчик». Сброс по `--days` добавляет, что пожизненные итоги правил
  и гайдов не имеют дня и потому остаются.
- «Копировать JSON» копирует конверт, который у панели уже есть: без вызова хоста, без файла и без новой
