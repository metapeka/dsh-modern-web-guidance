# 0.4.0 — the upstream v1.0.0 corpus, all 208 guides 📚

The catalog moves from **193 to 208 guides**: the whole `modern-web-guidance@1.0.0` release, taken
from the published npm tarball and shipped byte-identical. The tool surface, the sidebar panel and
the search engine are unchanged — upstream's v1.0.0 index is purely additive.

## 📚 Corpus

- **208 guides / 17 categories** (was 193 / 17) — **15 new, 105 rewritten, 0 removed**.
- New guides: `pwa/install-web-app`, `ui-atoms/single-line-overflow`, `ui-behaviors/drag-and-drop`,
  `ui-behaviors/dynamic-sort`, `ui-behaviors/sortable-table`, `ui-components/accordion`,
  `ui-components/app-menus`, `ui-components/breadcrumbs`, `ui-components/carousel`,
  `ui-components/copy-button`, `ui-components/navbar`, `ui-components/tabs`,
  `ui-components/toolbar`, `user-experience/form-factor-adaptation`,
  `user-experience/natural-interactions`.
- Snapshot `2026_11_09-5bcc021b`: 1.9 MB of markdown, ~475k tokens, 197 CLI cross-references across
  64 guides.
- `data/guides.json` is now upstream's `gen/guides.json` verbatim (upstream moved the index out of
  the package root), so the next refresh is a straight copy of that one file plus the guide tree.

## 🧪 Experimental guides announce themselves

Eighteen of the 208 guides sit behind an Origin Trial (8) or describe a feature that is volatile in a
single engine (10). They now say so:

- `web_guidance_search` marks such a hit `[experimental]`;
- `web_guidance_retrieve` opens with a `> [!WARNING]` banner naming the reason;
- the guide body stays byte-identical to upstream, and the banner counts against the
  120 000-character cap rather than against the five-guide limit.

## 🛠 Hardening that came with it

- The retrieve renderer builds its limit sentence from the payload instead of repeating the literals.
- Duplicate ids in the catalog are collapsed on read, so a malformed index cannot double-render a guide.
- A brittle "exactly 10 guides" test became a contract invariant: `guides + skipped == 208`, and the
  rendered body never exceeds the cap.
- 68 tests across 7 files, all green in CI.

## 📝 Skills and docs

- `SKILL.md` re-cut for v1.0.0: ported the implied-UI-primitives list and the "rephrase once before
  falling back to list" rule, added the legacy-audit text workflow, and stated plainly that upstream's
  `legacy-scan` engine is not shipped here.
- README ×3 (EN/RU/ZH): 208 badge, refreshed numbers, refresh instructions now point at
  `gen/guides.json` and say to ship 208 of the 209 markdown files.
- `NOTICE` records upstream 1.0.0 / `2026_11_09-5bcc021b`; the historical `audit/*` reports are
  untouched apart from a dated qualifier.

## 📦 Package

- 253 files, 842 kB packed, 2.4 MB unpacked, zero runtime dependencies, Apache-2.0.
- Published to npm over trusted publishing (OIDC) with a sigstore provenance statement; the tarball
  attached to this release is the same artifact.
