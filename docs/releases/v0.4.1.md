# 0.4.1 — a navigable README, a Chinese panel 🧭

The repository page now answers the questions a visitor actually has: what this is, how it differs from
Google's own package, what is in the corpus, which guides are experimental, and how to fix the usual
mistakes. The sidebar panel gained a Chinese dictionary. Nothing else moved: the same three tools, the
same 208-guide corpus byte-identical to upstream, still zero runtime dependencies and no network calls.

## ✨ Features

- The Guidance Insights panel ships a third dictionary: **32 strings** in Simplified Chinese, selected by
  the host locale alongside English and Russian.
- The plugin-list card follows: `locale/zh.json` carries a Chinese title and description, so the plugin
  reads Chinese in Discover too.
- Nothing else about the panel changed — same counters, same refresh, same bridge call. Chinese is data,
  not a new code path.

## 🛠 Hardening

- A new test file keeps the panel's three dictionaries in lockstep: **9 tests** asserting key and order
  parity between EN, RU and ZH, placeholder parity per key, a Chinese translation for every string, and
  one shared shape for the three `locale/*.json` cards. The suite is now **77 tests**.
- The panel's plural selector is untouched: Chinese defines one form per count phrase, which the existing
  selector reaches without any language-specific branch.

## 🧩 Compatibility

- Engine ranges are unchanged: DSH `>=0.2.0-rc.1 <0.3.0-0`, Node `>=22.19.0`. The Chinese dictionary is
  registered through the same `ctx.locale.register` call, under the locale id `zh`, so no host change is
  needed to pick it up.

## 📝 Skills and docs

- All three READMEs rebuilt around navigation: a collapsible contents block, **19** sections with
  **20** explicit anchors so links written against the old pages keep resolving, and one fixed emoji per
  section instead of ad-hoc formatting.
- New `🆚 vs Google's package`: an 11-row comparison that includes the parts this plugin deliberately does
  not ship — 9.16 MB of embedding assets and the 4.99 MB `legacy-scan` engine — next to what it adds:
  tools in the model's tool list, an install with no build step, and local usage analytics.
- New `🗺 Catalog map` with counts for all 17 categories, `🧪 Experimental guides` listing the 18 flagged
  ids, `❓ FAQ`, `🚦 Roadmap`, `📚 Docs map`, and a `Which tool when` table for the three tools.
- New `docs/README.md`: the repository map — every document, every code path, and a "where to change what"
  list, so nobody has to guess which file owns a behaviour.
- `docs/notes/readme-p0p1-spec.md` records the section order, anchors and emoji set, so the next README
  edit starts from the same shape rather than inventing a new one.

## 📦 Package

- **254 files**, **854 kB packed**, **2.5 MB unpacked**; the only additions are `locale/zh.json` and the
  longer `client.js`.
- Still **zero** runtime dependencies, Apache-2.0, and the tarball ships no docs, tests, audits or notes.
